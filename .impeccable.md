# Design Context — SassBlum

> Confirmado por el creador (Erick Armijos, ESPOL) en sesión. No inferido del código.

## Target audience
1. **Visitante nuevo** evaluando a la empresa (sitio de presentación/marketing).
2. **Cliente empresarial** que crea y da seguimiento a tickets de servicio.
3. **Personal interno** (trabajador / administrador) que gestiona tickets.

## Use cases / jobs-to-be-done
- Evaluar credibilidad y servicios de SassBlum (empresa IT, 20+ años: infraestructura, soporte, cableado, CCTV, domótica, servidores).
- Cliente: enviar ticket, ver estado/historial.
- Staff: asignar, cambiar estado, cerrar, reportes.

## Brand personality / tone
- **Inmersivo, futurista, alto-tech, premium.** Referencia explícita: sitios tipo Antigravity / Mimo con Three.js (partículas 3D, cursor reactivo, transiciones).
- El usuario adjuntó archivos estáticos (index.html/styles.css/scripts.js) como referencia exacta del *feel* deseado.

## Palette (NO negociable — mantener)
- Navy: `--brand-navy #0a1628`, `--brand-navy-deep #050d1a`
- Cyan de marca: `--brand-cyan #00d4ff`, acentos `#0891b2` / `#0e7490`
- Índigo de apoyo en gradientes: `#818cf8` / `#6366f1`
- Tipografía: **Space Grotesk** (display, `font-display`) + Inter (body).

## Aesthetic direction
Dark immersive con campo de partículas WebGL global (fijo), glass cards con tilt 3D + glow, cursor de 3 capas, botones magnéticos, marquee, count-ups, parallax. Ejecutar cyan-on-dark **con oficio** (jerarquía tipográfica fuerte, ritmo de espaciado variado, asimetría intencional, motion con easing exponencial, accesibilidad AA, prefers-reduced-motion) para que NO parezca plantilla genérica.

## Technical constraints
- React 19 + TS + Vite + Tailwind v4 + Framer Motion + three.
- JWT solo en memoria (nunca localStorage).
- Respetar `prefers-reduced-motion`; fallback móvil para 3D.
