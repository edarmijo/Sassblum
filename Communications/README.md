# Communications evidence index

This directory is the evidence index required by the final-project specification. It intentionally
contains no reconstructed conversations, private exports, credentials, or personal data.

Add only authentic, customer-authorized material. Store sensitive originals in an access-controlled
location and place a sanitized copy or an evaluator-accessible reference here.

## Required procedure

1. Preserve the original file and its timestamp in a controlled location.
2. Obtain permission before publishing customer messages, voice recordings, videos, or signatures.
3. Remove credentials and unnecessary names, phone numbers, email addresses, ticket data, and other
   personal information from the evaluator copy.
4. Record the participants, date and time, channel, decision, affected story or requirement, sprint,
   responsible team member, and authorization status in the table above.
5. Reference the same evidence ID from the report and traceability matrix.
6. Never replace missing evidence with a retrospective recreation.

The placeholder row must be removed only after authentic evidence has been indexed.
